## Problem Description

Given a sorted array of integers and a target value, return the index of the target if it exists. Otherwise, return -1.

## Approach Used

**Binary Search**

1. Initialize the search range using `low` and `high`.
2. Calculate the middle index.
3. Compare the middle element with the target.
4. If equal, return the index.
5. If smaller, search the right half.
6. Otherwise, search the left half.
7. Return -1 if the target is not found.

## Complexity Analysis

- **Time Complexity:** O(log n)
- **Space Complexity:** O(1)
